# Content Info Previews

Use these previews in Android Studio to validate safe-area and compact layout:
- activity_content_info_preview.xml: Full screen preview at 1920x1080.
- activity_content_info_scaled_preview.xml: Full 0.9 scale visualization.
- preview_action_buttons_row.xml: Six-button fit and focus/ripple alignment.
- preview_metadata_panel.xml: Quick check of title/meta/time rows and paddings.

Note: Previews are developer-only and not included in runtime builds.
