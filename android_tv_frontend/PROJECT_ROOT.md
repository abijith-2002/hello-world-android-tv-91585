# Android TV App Project Root

This directory is the root of the Android/Kotlin project for CI and tooling discovery.

Key markers:
- settings.gradle (includes :app, :list, :utilities)
- gradlew / gradlew.bat
- gradle/wrapper/gradle-wrapper.properties

Build commands:
- ./gradlew assembleDebug
- ./gradlew build

The primary application module is `:app`.
