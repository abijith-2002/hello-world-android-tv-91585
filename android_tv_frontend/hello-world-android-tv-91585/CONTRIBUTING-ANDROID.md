# Contributing (Android TV nested project)

- Android Gradle project root: android_tv_frontend/
- Use the nested wrapper: ./android_tv_frontend/gradlew
- Common tasks:
  - Assemble Debug: ./android_tv_frontend/gradlew :app:assembleDebug
  - Clean: ./android_tv_frontend/gradlew clean

From repo root, proxies are available:
- ./gradlew :app:assembleDebug
- make build
- ./build.sh
