# Android TV App – Project Root

The Android project is nested under:
- android_tv_frontend/

Build:
- From repo root: ./android_tv_frontend/gradlew -p android_tv_frontend :app:assembleDebug
- Or use helper: ./hello-world-android-tv-91585/build-android.sh

Outputs:
- android_tv_frontend/app/build/outputs/apk/debug/app-debug.apk
